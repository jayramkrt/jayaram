## 🚀 Featured Projects

### 💰 CashIgnite — Finance Calculator
> A comprehensive personal finance calculator built for real-world loan and EMI scenarios.

**Live →** [cashignite.in](https://www.cashignite.in) &nbsp; | &nbsp; **Source →** [GitHub](https://github.com/jayramkrt/CashIgniteFinanceCalculator)

**What it does:**

| Feature | Description |
|---|---|
| 📉 Reducing Balance EMI | Standard EMI calculation on reducing principal |
| 🔄 Prepayments | One-time & recurring; choose to reduce term or reduce EMI |
| 📈 Variable Interest Rates | Model changing rates over the loan tenure |
| 🏦 Interest Saver Account | Offset account to reduce effective interest |
| ⏸ Moratorium Period | Interest-only or capitalised moratorium support |
| 💳 Fees & Charges | Account for one-time and recurring fees |
